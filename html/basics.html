What is CUDA?

CUDA is parallel computing platform

It includes both an SDK and a compiler toolchain as it's core components

The core optimization techniques used in parallel programming are as follows:

  1. Memory Coalescing
  2. Shared Memory Tiling
  3. Thread Coarsening

Some advanced techniques covered later are:

  1. Bank Conflict Avoidance
  2. Double Buffering
  3. Tensor Cores (WMMA)
