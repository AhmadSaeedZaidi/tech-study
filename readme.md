Directory structure

This repository contains small practice projects and quick reference notes for learning HTML and CSS.

- `html` — practice HTML pages and examples.
- `css` — stylesheets used by the example pages in `html`.
- `notes` — short reference notes and reminders about HTML/CSS topics.
- `flexbox` — exercises and examples practicing CSS Flexbox.

Open the `html` pages in a browser to preview examples; edit the `css` files to see styling changes.
