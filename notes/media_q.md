# media queries
very useful, allow web page to become responsive, based on screen-size, orientation, basically the shape of the viewport.

the main syntax is
```css
@media <media-type> and (condition) {
  /* css rules */
}
```
for example, media type can be `screen` or `print`, and condition can be `(max-width: 600px)`.
versatile tool, can achieve a lot
