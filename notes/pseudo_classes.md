# pre-made pseudo-classes in CSS
these allow styling in specific, predefined states. Not much to cover here, look them up at [pseudo classes](https://www.w3schools.com/css/css_pseudo_elements.asp)

notable ones:
## hover:
style when hovering
## active:
style when the element is clicked/active
## valid:
style when a valid input is in the input field.

# pseudo-elements:
elements are divided into pre-defined parts, like the first letter, or first line. these can be accessed and styled with pseudo-elements. look them up at [pseudo elements](https://www.w3schools.com/css/css_pseudo_elements.asp)

important ones are:
## ::first-letter, ::first-line:
style the first letter or line of an element.
## ::before, ::after:
insert content before or after an element's content. useful for adding decorative elements or icons without extra HTML.
## ::selection:
style the portion of text selected by the user.
